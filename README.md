# Oqu — подготовка к КТ

Адаптивный сайт с двумя направлениями — «Пробники» и «Обучение» — для подготовки к комплексному тестированию в магистратуру. Работает без регистрации, сервера приложений и внешних API.

## Запуск

Из папки проекта:

```sh
python3 -m http.server 3000
```

Откройте http://localhost:3000. Для использования достаточно и обычного открытия `index.html`; HTTP-сервер обеспечивает стабильное сохранение истории в браузере. Статические файлы также можно разместить на GitHub Pages или любом статическом хостинге.

## GitHub Pages

Сайт: https://make-free.github.io/oqu/

Все файлы сайта хранятся в корне этого репозитория. GitHub Pages публикует ветку `main` из `/ (root)`. После обновления файлов в `main` сайт обновляется автоматически; сборка и зависимости не нужны. Файл `.nojekyll` отключает обработку Jekyll.

Сайт работает независимо от подписки и аккаунта ChatGPT. Его также можно скопировать на любой статический хостинг.

История попыток и закладки хранятся в браузере отдельно для каждого домена. При переходе с другого адреса сайта они автоматически не переносятся.

## Направления

- «Пробники»: три пробника ТГО по 30 вопросов и один пробник по английскому языку на 50 вопросов: 16 Listening, 18 Grammar и 16 Reading.
- «Обучение»: отдельные направления «Критическое мышление», «Аналитическое мышление» и «Английский язык». Активные учебные тесты временно убраны.
- В «Критическом мышлении» программа разделена на 30 учебных тем: от арифметики и уравнений до геометрии, комбинаторики, графиков и таблиц.
- Для первой темы «Числовые множества и сравнение» доступен последовательный конспект на русском и казахском языках: теория, алгоритмы, примеры и самопроверка.
- В «Аналитическом мышлении» доступны 7 тем по работе с текстом: от определения главной мысли до проверки утверждений и поиска синонимов.
- Прежние результаты комбинированных пробников сохранены в истории, но сами комбинированные варианты убраны из активного каталога.
- Первый и второй отдельные пробники ТГО используют самостоятельные блоки из 15 задач на критическое мышление; каждый дополняется 15 заданиями на аналитическое мышление.
- Вопросы пробника перемешиваются внутри блоков, порядок блоков сохраняется. После завершения показываются общий результат и результаты по блокам.
- Прежние учебные тесты убраны из каталога, но их результаты и разборы сохраняются в истории.

## Возможности

- В обучении критическое и аналитическое мышление больше не объединены под пунктом «ТГО».
- 4 активных пробника: три по ТГО и один по английскому языку.
- 140 активных вопросов с объяснениями в пробниках; прежний учебный банк хранится для разбора старых попыток.
- Поиск, фильтры и сохранение тестов в закладки.
- Настройка таймера и перемешивания вопросов.
- Навигация по вопросам, флажки и изменение выбранных ответов до завершения.
- Автоматическое завершение по таймеру; подтверждение при досрочном завершении или выходе.
- Встроенное воспроизведение заданий Listening голосом браузера без внешнего сервиса; транскрипт показывается в разборе.
- Результат и разбор всех ответов, фильтр ошибок, повторное прохождение.
- История последних 50 попыток и сводная статистика в localStorage этого браузера.
- Мобильная версия и управление с клавиатуры. Клавиша `/` открывает поиск.
- Переключатель интерфейса между русским и казахским языками с локальными SVG-флагами; выбор сохраняется в браузере.
- На главной странице размещено авторское введение с рекомендациями по последовательной подготовке.

Задания учебные, не являются официальным банком НЦТ. Количество вопросов и время практики могут отличаться от официального КТ. Английский блок пробника содержит 50 вопросов. Прежние попытки удалённых тестов доступны для разбора в истории.

## Файлы

- `index.html` — страница и базовая навигация.
- `style.css` — оформление и адаптивная верстка.
- `script.js` — каталог, прохождение, результаты и история.
- `i18n.js` — русские и казахские переводы интерфейса.
- `questions.js` — прежний учебный банк, варианты и объяснения.
- `mock-questions.js` — прежний английский банк для истории, задания Reading и два отдельных блока первого пробника ТГО.
- `tgo-mock-2.js` — самостоятельный блок из 15 задач для второго пробника ТГО.
- `english-mock-v2.js` — активные блоки Listening и Grammar и дополнительное задание Reading для английского пробника.
- `fonts/` — локальные шрифты Manrope и Noto Sans для полного казахского алфавита, а также их лицензии SIL OFL.

Шрифт, иконки и данные хранятся в проекте. Сайт не обращается к внешним сервисам. История не синхронизируется между устройствами; незавершённая попытка не сохраняется после закрытия страницы.
